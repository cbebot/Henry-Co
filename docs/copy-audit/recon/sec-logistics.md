## B3. Logistics (`apps/logistics`)

Key mechanics:
- **Price engine** `apps/logistics/lib/logistics/pricing.ts:137-168`: total = (zone base fee + rate-card base) + urgency uplift (rate base × 0.2 priority / × 0.45 rush, plus zone same-day multiplier on same-day) + weight × per-kg + size surcharge × tier multiplier (1 / 1.25 / 1.6 / 2.1) + fragile fee + inter-city uplift. Default rate cards `pricing.ts:10-83`; zones `lib/logistics/content.ts:195-250` and DB seed `apps/hub/supabase/migrations/20260405150000_logistics_customer_surface.sql:232-237` (Enugu Urban ₦3,000 · 2–6 h; Enugu Outskirts ₦4,500 · 4–10 h; Other Igbo States ₦8,500 · 8–24 h; Inter-city Priority ₦12,000 · 10–36 h).
- **Web quote & booking** both call `createLogisticsRequest` (`lib/logistics/write.ts:91-188`) with DB zones/rate cards (`write.ts:123-137`; `lib/logistics/data.ts:331-347`). A web quote is saved as its own "quoted" shipment (`write.ts:144-148`; `app/actions/logistics-booking.ts:126-127`); there is **no web path that converts a saved quote into a booking** — booking re-prices from the current tables. The JSON `/api/logistics/quote` prices from the static defaults (`app/api/logistics/quote/route.ts:78-102`) and `/api/logistics/book` re-prices again (`app/api/logistics/book/route.ts:125`).
- **"Confidence %"** shown on /track is a fixed heuristic: start 86, minus fixed amounts for inter-city / rush / size, clamped 55–98 (`pricing.ts:120-135`) — not measured. (`content.ts:111-115` describes a rider-load/issue-history model that does not exist.)
- **Proof of delivery**: every shipment is flagged `requires_pod: true` (`write.ts:184`); PoD capture exists for rider/dispatch roles with photo and signature both optional (`app/api/logistics/pod/route.ts:43-117`). No code found that blocks "delivered" without a PoD.
- **Event log**: `logistics_events` (`20260405150000_logistics_customer_surface.sql:125-138`) has no append-only guard; client roles are locked out (`20260614120000_sec_harden_03_world_writable_lockdown.sql:60-72`) but the server role can update/delete.
- No VAT, refund, cancellation or insurance statement is rendered on logistics public routes. (A customer claims endpoint exists, `app/api/logistics/claims/route.ts:7-16`, but no public copy promises compensation.)
