## B1. Marketplace (`apps/marketplace`)

Key mechanics (read once, cited below):
- **Buyer-side pricing**: `packages/pricing/src/index.ts:231-246` — delivery flat **₦18,000**, free when items subtotal **≥ ₦350,000**; buyer platform fee **0**. Applied server-side at `route.ts:664-672`. One delivery line per order regardless of vendor count (`index.ts:276-279`).
- **Client display of shipping** uses a different rule: `checkout-experience.tsx:229` and `cart-experience.tsx:188` → free only when subtotal **> ₦350,000** (strict), and they do not know about the seller-promise / manual free-delivery waiver (`route.ts:587-662`, `lib/checkout/free-delivery.ts:67-84`). At exactly ₦350,000, or when a waiver applies, the summary shows ₦18,000 while the server charges ₦0.
- **Hold ("escrow")**: card → order + groups `paid_held` on settlement (`lib/checkout/sale-reconcile-port.ts:229-239`); wallet → `paid_held` at order creation (`route.ts:760`, `859-860`); manual transfer → `paid_held` when finance verifies (`route.ts:2075-2093`). **COD is never held**: order `placed`, vendor group `awaiting_payment` (`route.ts:760`, `859-863`).
- **Release**: buyer "confirm completion" → `payout_releasable`, blocked while a dispute is open (`route.ts:2160-2175`); otherwise auto-release after the tier's `autoReleaseDays` (1–5) counted from the **seller-reported** `delivered_at` (`governance.ts:219`, `383-401`; `lib/marketplace/automation.ts:209-215`, `252-283`). "Delivered" is set by the vendor's own `vendor_order_update` (`route.ts:2523-2590`) — no delivery proof is required.
- **Payout reserve** days (`payoutDelayDays`, `governance.ts:218`) are computed but **never enforced** — not used by automation, payout request (`route.ts:2435-2466`) or decision (`route.ts:2832-2878`); only displayed on vendor pages.
- **Dispute**: buyer-opened (ownership-gated) → order `disputed`, group `payout_frozen` (`route.ts:2223-2256`). Staff resolution `refund_to_buyer` only sets group `payout_status='refunded'` and writes "a refund has been issued" to the timeline (`route.ts:2333-2358`) — it moves **no money**. Real refunds exist only as a staff-only card-intent refund (`apps/account/app/api/payments/intents/[id]/refund/route.ts:13-20, 47-51`: customer self-serve refunds "deliberately-unbuilt"). `marketplace_refunds` (`supabase/migrations/20260514120500_marketplace_refunds.sql`) and `marketplace_returns` (`20260402180000_marketplace_init.sql:415-425`) tables exist but no buyer return/refund flow writes them (only a staff read, `lib/marketplace/data.ts:1431`).
- **Seller economics**: plans `governance.ts:93-146` (Launch ₦0/mo · 3 listings · posting ₦3,500 · featured ₦15,000 · 15% commission · payout 2%+₦300; Growth ₦25,000/mo · 20 · ₦2,500 · ₦10,000 · 12% · 1.5%+₦250; Scale ₦85,000/mo · 999 · ₦0 · ₦6,000 · 9% · 1%+₦250; Partner custom/0). The **plan applied is derived from the trust tier**, not chosen (`governance.ts:207-208`). Commission + payout fee are computed and stored per order group at checkout (`governance.ts:354-381`; `route.ts:845-867`). **Monthly plan fees, posting fees and featured fees are never billed**: monthly fee is display-only (`policy.ts:186`, `seller-application-wizard.tsx:321-325`); posting/featured fees are only written into `filter_data` (`route.ts:1808-1814`).
- **Seller "verification"**: approval sets `verification_level` from shared KYC — verified→gold, **pending→silver**, none→bronze (`route.ts:58-63`, `1921-1941`) and seeds trust metrics `response_sla_hours 6`, `fulfillment_rate 93`, `dispute_rate 2.5`, `review_score 4.5` (`route.ts:1943-1946`). Those stay until ≥3 orders / ≥5 orders / ≥2 reviews (`lib/marketplace/trust.ts:365-388`); `response_sla_hours` is never recomputed (`trust.ts:423-431`). Public catalog = vendors with `status='approved'` (any verification level) (`data.ts:294`).
- **VAT**: carved INCLUSIVE from the gross at checkout; customer total unchanged (`route.ts:674-697`; `packages/pricing/src/vat.ts:128-135, 144-147, 170-174`; rate `packages/config/tax.ts:33-48` = 7.5%). **No marketplace public surface currently states anything about VAT** (checkout summary = Subtotal / Shipping / Total only, `checkout-experience.tsx:1766-1783`).

A web quote is saved as its own "quoted" shipment (`write.ts:144-148`; `app/actions/logistics-booking.ts:126-127`); there is **no web path that converts a saved quote into a booking** — booking re-prices from the current tables.
